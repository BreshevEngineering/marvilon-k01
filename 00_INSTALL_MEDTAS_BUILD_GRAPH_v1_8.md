# Install MEDTAS Build Graph v1.8

1. Close any old MEDTAS Center server window if desired. SolidWorks may remain open.
2. Extract this overlay directly into:
   `D:\BreshevEngineering\marvilon-k01\`
3. Replace existing overlay files.
4. Run:
   `03_RUN_MEDTAS_PIPELINE.cmd`
5. Start the working UI:
   `OPEN_K01_COMMAND_CENTER_V11.cmd`
6. In Overview, confirm that **DO NOW** points to Product Definition / Drawings / BOM rather than CalculiX.
7. Use **Build AI Handoff ZIP** before sending the current state for review.

No existing engineering files are automatically moved, deleted or renamed by the project-structure audit.
