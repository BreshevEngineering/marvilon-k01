# K01 Technology System v2

Every MAKE configuration item shall have:
material/certificate → stock → operation sequence → setups/datums → critical
dimensions → process capability → intermediate inspection → final inspection →
finish/deburr → cleaning/passivation → joining/heat treatment → leak/electrical/
force test → acceptance → rework/nonconformance.

Technology links directly to CI IDs and EDR IDs.

A design alternative that passes FEA but requires unrealistic process capability,
unavailable stock, destructive maintenance or costly extra setups does not pass
EDS-001.
