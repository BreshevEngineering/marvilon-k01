# K01 Technology System v1

Manufacturing technology is a controlled engineering domain.

Each MAKE part shall ultimately define:
material/certificate → stock → operation sequence → setup/datums → process-critical dimensions → intermediate inspection → final inspection → edge/deburr → surface finish → cleaning/passivation → joining/heat treatment → leak/electrical/force test → acceptance → rework/nonconformance.

Technology must be linked to EDRs, controlled dimensions, drawing/PMI, BOM, inspection method, material status and release revision.

An OPEN material or process stays OPEN. It is not inferred to make the table look complete.
