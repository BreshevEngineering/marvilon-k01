# K01 file policy

## CAD workspace

Only stable production files are allowed as sources in the top assembly:

- `cad/assemblies/K01-A-001_Calibration_Module.SLDASM`
- `cad/parts/K01-P-xxx_*.SLDPRT`

`cad/candidates` is temporary engineering evidence only. The top assembly shall
never remain permanently linked to a candidate timestamp filename.

## Candidate states

After a gate closes:
- ACCEPTED geometry -> promote to stable production filename after backup.
- REJECTED -> `cad/archive/rejected/<date>/`
- VERIFICATION assemblies -> `cad/archive/verification/<date>/`
- Simulation result sets -> `cad/archive/simulation/<date>/`
- temporary `~$*` files -> delete only with SOLIDWORKS closed.

## Git repository

Track:
- master JSON;
- params/source scripts;
- current gate summaries;
- small JSON/CSV evidence;
- BOM projection;
- requirements/change control;
- QA tests.

Do not track in ordinary Git:
- SLDPRT/SLDASM/SLDDRW;
- CWR/rsl/large solver output;
- handoff zips;
- generated screenshots;
- generated STEP unless deliberately placed in Git LFS/PDM.

## Root folder

Root should contain only project-level entry points and control files.
Gate-specific debug/history and superseded engineering sources belong under `archive/`, never in active `docs/history`, `cad_api/history`, `.local_archive`, or the root. Archive content is excluded from default AI handoff and is never active authority.


## CURRENT / temporal precedence

`CURRENT` in a filename is not a timestamp and is not authority by itself.

Global session/navigation `STATE_CURRENT` files are generated by the centralized reducer
`tools/state/k01_current_state_reducer_v1.py` and must share
`control/state/K01_STATE_EPOCH_CURRENT.json`.

Domain `*_CURRENT` reports are current only inside their declared engineering domain.
They cannot override `control/project/K01_CURRENT_SESSION_MANIFEST.json` for Goal Lock,
active deliverable, current artifact, chronology, or next action.

`run.cmd handoff` must fail closed unless
`reports/control/K01_TEMPORAL_COHERENCE_CURRENT.json` is
`PASS_TEMPORAL_COHERENCE`.

See `docs/architecture/K01_TEMPORAL_AUTHORITY_POLICY_v1.md`.
