Engineering domains

J2 C2R1 · decision summary

Decision: keep OD33 / 3×M2.5 / PCD26.5 compact removable flange. Geometry is frozen. Production release is being closed by tolerance, seal, preload, service, structural, drawing and test evidence.
What is fixed now
Removable P003↔P007 boundary; 316L/316L; Ø14.10 pilot/locator; metal-face axial datum; 3-screw clamp; static O-ring seal; P007 L35; zero new hard interference.
Why this design / rejected alternatives
Permanent weld rejected for serviceability. Ø16 pilot rejected by actual P007 architecture. OD34/PCD28/M3 rejected by ligament. OD36/M3 kept only as bulky verified reference. C2 ID10.917 rejected by exact P006 collision. C2R1 ID12 removed that collision while preserving compact OD33.
Key calculations
Head clearance H9/h9: 0.250…0.293 mm radial Fastener-pattern worst-case margin: 0.0575 mm radial O-ring gland fill with v8 tolerances: ~61…85% Preload design window: 200…300 N / screw Thread strip SF at 300 N/screw: ~3.10 Residual face clamp at minimum preload, seal force 300 N: ~296.9 N Conservative local flange strip-bending screen at 300 N/screw: ~135.6 MPa
Manufacturing / inspection
P003/P007 remain conventional turned/drilled 316L parts. Drawing-intent specs define characteristic IDs and inspection method. Small M2.5 tapping and P006 two-pin service holes require first-article capability checks.
Service / thermal / galling
Two-pin hollow face driver selected for P006. Dry stainless-on-stainless torque-controlled installation is not release baseline. Exact finish/lubrication must be qualified in the same condition used for torque-preload calibration. 50 service cycles are a provisional qualification target.
Safety / seal
FKM 75A is the preferred cost/availability candidate for the bounded current BOF release. FFKM remains the controlled fallback. Exact J2-local temperature, media envelope, supplier compound, compression force and leak qualification remain mandatory.

Bidirectional data flow

Design → execution

Requirements / EDR define what must be built and why.
MEDTAS commands open or build controlled CAD, project BOM metadata, generate drawings and launch solver/test work packages.

Execution → evidence

SOLIDWORKS / Simulation / FEMM / tests return exact artifact/result evidence with path, time, status and eventually fingerprints/hashes. UI buttons never create PASS by themselves.

Evidence → decision

The state reducer and Technical Filter compare current evidence against requirements and release gates. Missing, stale or inconsistent evidence keeps the parent gate HOLD.

Manufacturing / inspection → design

Capability, inspection and service/test results must be able to reopen the affected decision/CAD/drawing chain. This is the reverse direction that prevents a one-way PDF process.

Change-impact examples

If P003/P007 geometry changesReopen assembly verify/interference → tolerance chains → structural checks → BOM/drawings → FEMM geometry fingerprint → release.
If O-ring compound changesReopen media compatibility → compression force/preload → thermal/service → BOM/supplier → drawing/process notes → release.
If B001 supplier magnet changesReopen material/Br(T)/dimensional evidence → FEMM → actuator acceptance → BOM/supplier → bench release.
If inspection finds nonconformanceInspection evidence links back to characteristic → tolerance/process/EDR → CAD/drawing revision → re-verification.
