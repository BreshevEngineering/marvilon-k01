## Why Gate04E is rerun once

The previous v2 report shows `front_plane_x_mm = 1000`. That is not a physical P006 dimension.  
SOLIDWORKS `Surface.PlaneParams` returns:

`normal.x, normal.y, normal.z, rootPoint.x, rootPoint.y, rootPoint.z`

with root point in metres.

The previous builder used element 0 as X; Closure 03 corrects X to element 3 and uses element 0 only as the fallback surface-normal X component.

The existing candidate probably received its sketch on the intended +X face, but its coordinate evidence is not release-quality. Closure 03 regenerates it from stable CAD and produces trustworthy readback before T03 is closed.
