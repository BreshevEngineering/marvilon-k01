# Install MEDTAS v1.6

Copy/expand this overlay directly into:

`D:\BreshevEngineering\marvilon-k01\`

with replacement of older MEDTAS files.

Then run:

`03_RUN_MEDTAS_PIPELINE.cmd`

and use:

`OPEN_K01_COMMAND_CENTER_V10.cmd`

as the single local-server UI.

Do not use the generated static `reports\control\K01_MEDTAS_CENTER_CURRENT.html` as the primary control center; it is diagnostic evidence only.
